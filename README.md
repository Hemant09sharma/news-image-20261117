Tuesday 17 November 2026, in one picture. The picture is stored at `assets/entry.png`. The program reads that file and writes the same bytes to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Leave `MAKEFUN_OUTPUT_DIR` unset when the grader supplies `/output`. The program uses the Node.js standard library only. It does not install packages, call the network, or change the picture.
